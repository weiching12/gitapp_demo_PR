# 文字層級

所有畫面的字級、字重與行高集中於 `src/typography.css`，版面與外觀放在 `src/styles.css`。字級使用 `rem`，以瀏覽器預設 16px 換算如下。寬度 700px 以下採較緊湊的標題層級。

| 層級 | 預設大小 | 用途 |
| --- | --- | --- |
| `--text-page` | 32px | 頁面主標題 |
| `--text-section` | 24px | 區塊／視窗標題、卡片主要數值 |
| `--text-title` | 20px | 股票名稱、子區塊標題、手機法人合計 |
| `--text-body` | 16px | 內文、表格數據、輸入欄位、法人比較數值 |
| `--text-secondary` | 14px | 區塊副標、指標標籤、技術說明、操作按鈕 |
| `--text-meta` | 12px | 日期、單位、代碼附註、狀態標籤；手機精簡導覽文字 |

手機主標題及股票名稱最多 15px；一般文字、主要數值與產業名稱為 14px；次標題、說明及次要資訊為 12px。產業排行工具列的六個排序與期間選項及交易日下拉選單為 12px；一般漲跌幅數據為 15px，產業排行列的漲跌幅為 12px。排行列的 TOP1 說明與百分比統一為 12px 和同一文字色。

標題行高 1.35、按鈕與短標籤 1.5、說明文字 1.65。字重僅使用 400（一般）、500（標籤／操作／數據）與 600（標題／重要數據）。

新增元件依用途使用既有層級，不另訂個別 px 字級。螢幕變窄時，透過換行、堆疊或表格橫向捲動調整版面；內文與輸入欄位維持可讀字級。主要操作的觸控範圍至少 44px，手機版產業排行工具列選項為 40px 寬、34px 高。
