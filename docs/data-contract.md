# 正式資料串接介面

目前僅提供可操作的前端示範，沒有自動抓取正式行情、沒有 API 金鑰，也沒有設定 Cloudflare。

`src/data.js` 的 `demoProvider.load()` 是資料來源的替換點，回傳下列結構：

```js
{
  info: {
    mode: 'demo', // 正式資料改成適當的來源識別，並同步調整 UI 的示範標示
    label: '示範資料',
    asOf: '2026-10-16', // 以 Asia/Taipei 的實際完整交易日為準
    note: '資料來源、更新時間及限制'
  },
  dates: ['2026-10-15', '2026-10-16'], // 實際有完整資料的交易日，舊到新
  stocks: [{
    symbol: '2330', // 字串，0050、00878 必須保留開頭的 0
    name: '台積電',
    sector: '半導體',
    market: '上市',
    history: [{
      date: '2026-10-16',
      open: 1000,
      high: 1020,
      low: 990,
      close: 1010, // OHLC 單位皆為新台幣
      volume: 10000000, // 單位：股，非張
      institutions: [
        { name: '外資', buy: 2000000, sell: 1000000 },
        { name: '投信', buy: 500000, sell: 300000 },
        { name: '自營商', buy: 200000, sell: 400000 }
      ] // buy、sell 均為股數
    }]
  }]
}
```

範例金額僅說明格式，不是正式行情。股數只在畫面與匯出時除以 1,000 換算成張；法人買賣超使用未經四捨五入的股數加總。畫面成交張數取整數，CSV 保留小數。

## 計算約定

- 歷史資料必須依日期由舊到新排列，不能有同一股票重複日期。
- `asOf` 不能直接以昨天的日曆日期推定；需要台灣交易日曆，以及行情與法人資料均完整的日期。
- `getSnapshot()` 先截斷到選定資料日，再計算所有指標，避免讀取未來資料。
- MA5、MA20、MA60 分別取最近 5、20、60 個交易日的收盤價平均，包含當日。資料不足時回傳 `null`。
- 預設 KD (9,3,3)，第一個完整 9 日窗口才開始遞推。前值 K、D 為 50；全平盤窗口 RSV 採 50。修改平滑係數時使用 `(n - 1) / n` 與 `1 / n`。
- 保留足夠的歷史暖機期。相同 KD 參數若暖機起點不同，初期值可能不同；應與資料供應商確認算法。
- 示範資料未做除權息／分割還原。正式資料需決定並一致使用還原或未還原價格，並標示口徑。
- 法人資料需確認外資包含範圍，以及自營商自行買賣／避險的合併規則。買進、賣出與買賣超需使用同一資料口徑。

## 下一階段

選定台灣證交所、櫃買中心或授權供應商後，再處理資料授權、API 回應驗證、缺漏值、錯誤與載入狀態、快取及更新排程。金鑰若為機密，應放在 Cloudflare Worker 或其他後端，不能放入瀏覽器或 `VITE_*` 變數。

目前首頁及匯出明確顯示模擬資料。正式資料接通之前請保留這些標示；接通後需要一起更新資料來源資訊、日期邏輯與標示，不能只更換 provider。
