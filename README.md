# 株研 Stock Insight｜台股研究室

繁體中文的股票分析前端，使用原生 JavaScript、CSS、SVG 與 Vite。支援本機示範模式，以及 Cloudflare Workers Static Assets + Workers KV 的正式資料模式。部署與資料來源設定見 [docs/cloudflare.md](docs/cloudflare.md)。

正式網站：[株研台股研究室](https://stock-insight-tw.stock-insight-tw.workers.dev/)。2026-10-18 已部署 TWSE 全上市公司資料與每日排程，並通過正式網站 API 與瀏覽器驗證。

## 目前資料狀態

`npm run dev` 與一般建置保留明確標示的示範模式：14 檔上市、上櫃股票／ETF（含禾伸堂 3026、環球晶 6488），各有 180 個模擬交易日，固定截止 **2026-10-16**。

`npm run build:cloudflare` 使用臺灣證券交易所的免費公司名錄、每日收盤行情及 T86 法人 JSON 報表，首次建立 90 個市場交易日，之後每日累積，從 Cloudflare KV 讀取最多 260 筆交易歷史。範圍為官方名錄全部上市公司（含存託憑證，不含上櫃及 ETF），2026-10-18 實測 1,096 家；每日名錄更新，不固定檔數。程式設定平日台灣時間 18:30、20:30 各驗證一次 T86，通過日期、19 欄結構、整數、算式與動態筆數門檻後，才以 D1 暫存及交易 Upsert，再分批發布 KV；相同 Hash 不重寫逐股資料，失敗保留最後成功版本。正式啟用前須建立 D1、套用 migration 並人工確認初始基準，詳見 [T86 同步與啟用步驟](docs/t86-sync.md)。停牌與來源缺漏不補零，也不拖住全市場日期；錯誤保留舊版。價格未還原、非即時報價；正式模式不退回模擬資料。

首次上線資料涵蓋 2026-06-08 至 2026-10-16，共 90 個市場交易日、97,854 筆個股價量歷史，KV 資料約 6.72 MiB。新上市、停牌及來源缺漏可能使個股歷史少於 90 筆；1,096 筆名錄包含 1,086 家一般公司及 10 檔存託憑證。年度休市表與官方七月份成交月報均已交叉核對。

兩種模式均由歷史 OHLC 在瀏覽器實際計算 K、D、均線及法人近 5／20 日累計與連續買賣日數。新增的兩檔預設加入自選；既有偏好只遷移一次，後續移除不會自動補回。

## 啟動專案

建議使用 Node.js 22.12 以上或 Node.js 24 LTS。

```bash
npm ci
npm run dev
```

在執行專案的電腦開啟終端顯示的 Local URL，預設為 `http://localhost:5173`。遠端開發環境需使用平台支援的連接埠轉送；遠端的 localhost 不等於你的電腦。

```bash
npm run build
npm run preview
```

正式建置輸出為 `dist/`。本機建置預覽預設位於 `http://localhost:4173`。圖片與程式由專案本身提供，沒有外部字型或第三方 CDN 依賴；正式模式由排程取得 TWSE 資料，瀏覽器僅讀取同源快取 API，不直接呼叫交易所。

## 已完成的功能

- 全站使用一致的六級字體規則（12／14／16／20／24／32px）；手機版主標題最多 15px、一般文字 14px、次要資訊 12px。字級與行高集中於 `src/typography.css`，規則見 [文字層級](docs/typography.md)。
- 股票名稱／代碼搜尋、產業篩選、欄位數值排序。
- 正式模式先顯示頁面與載入進度，自選股優先取得，每批股票驗證與計算完成便更新清單；載入中可搜尋、排序及收藏。既有資料列與指標計算會重用，避免每批重建全表。產業統計於全市場載入完成後顯示；下載失敗會保留已取得的清單、標示未完成並提供重新載入。
- 價量總覽以摘要卡片顯示所有自選股，保留收盤價、成交量、KD、股價與季線；桌面並排、手機左右滑動。法人資訊集中於「法人總覽」，價量卡片不提供重複入口。
- 手機價量卡片改為左右滑動，保留完整內容並顯示目前檔數；可使用前後按鈕，超過 10 檔時可用股票選單快速跳轉。加入自選會滑至新卡片，桌機與平板維持原排列。
- 自選總覽可切換「價量總覽／法人總覽」，後者一次比較全部自選的合計、外資、投信、自營商買賣超及連買／連賣天數，可切換當日、近 5 日與近 20 日；詳細買賣量仍可從各列開啟。
- 手機法人總覽以合計摘要搭配三家法人逐列對齊數字，連買連賣標籤放在名稱旁；區間切換在捲動時保留於導覽下方，合計區塊只顯示標題與張數。桌機與平板維持原比較排列。
- 下方市場觀察清單可用星號新增／移除自選，上方立即同步；自選保存在目前瀏覽器的 localStorage，不會跨裝置同步。搜尋與篩選下方表格不影響上方自選範圍。
- 手機從市場清單加入自選時，畫面定位到上方該股票卡片；移除自選時保留清單位置，桌機與平板新增時也保留操作列及橫向捲動。自選篩選中以鍵盤移除一列後，焦點移到相鄰股票。手機與平板提供含文字的固定導覽、至少 44px 的主要觸控範圍，市場表格固定收藏與股票名稱欄。
- 資料來源與涵蓋範圍放在側欄「資料說明」；主畫面以示範／每日收盤資料區分模式，卡片不顯示重複日期與來源，頁尾保留「技術提示僅供研究參考」。
- 最近 30 個資料日回看；切換資料日會同步重算指標和法人明細。
- 產業法人排行與明細顯示資料完整個股的區間加總；有缺漏時標示「已統計 X／Y 檔，部分資料缺漏」。當日、5 日與 20 日分別計算涵蓋率，合計與三家法人使用同一批個股；個股缺漏不補零。
- 收盤價、日漲跌與成交量；台股慣例紅漲綠跌。
- 市場清單以「日漲跌幅」呈現每日漲跌，成交量以張顯示在收盤價下方；手機固定收藏與股票欄合計約 116–132px，長名稱完整換行，保留價格及日漲跌的閱讀空間。
- 市場清單的法人買賣超下方標出當日買超或賣超最多的法人類別；買賣超持平或資料不足時不指定單一法人。
- 手機法人總覽逐檔左右滑動，提供目前檔數、前後按鈕與超過 10 檔時的快速選股；桌機與平板仍一次顯示所有自選法人比較。
- KD 預設 (9,3,3)，可調整 RSV 回溯週期及 K、D 平滑係數。
- 觀察清單顯示 D 值與 KD 技術建議、判讀原因；依當日交叉與 MA20 趨勢區分買點、賣點、反彈及觀察狀態，並提供判讀規則視窗。
- 收盤價相對 60 日季線的乖離率；站上季線、K 值低於 20 篩選。
- 外資、投信、自營商買進、賣出與買賣超，畫面統一以張顯示。
- 法人總覽各列的「明細」開啟視窗，顯示三大法人合計、買賣明細及近 5／20 個交易日累計；外資、投信另顯示連買／連賣日數。視窗標示股票與資料日，可用關閉按鈕、Escape 或背景關閉並回到原列按鈕；切換資料日同步重算。
- 手機版排版、可橫向捲動的行情表格、鍵盤搜尋捷徑 `/`，及可用 Escape 關閉的說明視窗。

上方僅呈現自選標的；沒有自選時顯示選股引導，不會自行補上其他股票。原價格與技術走勢區塊、CSV 匯出及市場清單的近月走勢欄位已移除。

## 驗證

```bash
npm test
npm run build
```

單元測試涵蓋獨立計算案例、季線、歷史截斷、篩選、資料一致性、法人累計／連續日數與技術建議。Playwright 測試涵蓋多檔摘要、法人視窗開關與股票身分、鍵盤與焦點復原、法人數值、換日、排序、搜尋、自選增減與保存、空清單、參數調整、建議重算與 320–1920px 排版。

```bash
# 第一次執行瀏覽器測試，在本機安裝 Chromium
npx playwright install chromium
npm run test:e2e
```

若環境有 `/usr/bin/chromium` 則直接使用；也可以用 `CHROMIUM_PATH` 指定瀏覽器執行檔。Playwright 會自動啟動 Vite，不須另開伺服器。

## 程式結構與後續部署

```text
index.html                 入口
src/main.js                自選總覽、畫面、互動與狀態
src/styles.css             桌面與手機版面
src/indicators.js          技術指標與篩選純函式
src/data.js                模擬資料
src/provider.js            市場索引與分組歷史讀取、版本驗證
src/market-codec.js        緊湊數值歷史展開
cloudflare/                TWSE 正規化、Worker 快取 API 與分批排程
scripts/seed-market.js     單線限速、可續接的全市場歷史回補
wrangler.jsonc             部署、KV、排程設定
docs/data-contract.md      正式資料格式與串接注意事項
tests/                     計算與瀏覽器測試
```

一般 `npm run build` 產出示範模式；`npm run dev:cloudflare` 在 `http://localhost:8787` 預覽正式模式。先用 `npm run seed` 下載最近 90 個交易日，再依 Cloudflare 文件匯入 KV；之後每日累積至最多 260 筆。回補請求至少間隔 10 秒，正常約 30 分鐘以上，成功下載立即快取，中斷後重跑可續接。每日正常僅三個整批 TWSE 請求，週五另四個請求複查近期修正，不需行情 API Token。`npm run deploy` 建置正式模式並部署。

正式資料串接契約與算法約定請見 [docs/data-contract.md](docs/data-contract.md)。
